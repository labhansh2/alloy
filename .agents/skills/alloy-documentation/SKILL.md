---
name: alloy-documentation
description: Guides documentation changes in Alloy. Use when documenting prototypes, findings, architecture, or design research.
---

- Document meaningful findings, not every code change: bottlenecks, API decisions, and validated architecture.
- Keep prototype documentation in `docs/prototype/`.
- Reserve the root of `docs/` for architecture, core design, and research documents.
- Update existing documents where possible; avoid redundant notes.
