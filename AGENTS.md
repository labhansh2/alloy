## Formatting (required)

After any code change, follow `.agents/skills/alloy-formatting/SKILL.md` and run `pnpm format` across the entire repo, then `pnpm format:check` before finishing. Go formatting includes `wsl` blank-line fixes; preserve readable logical sections in every language.
