### current status

- Research and prototyping: Alloy is not yet a production-ready system.
- Building toward a self-owned, distributed intelligent system, with a shared server foundation and ordinary, connectable program nodes.
- Intended entry points: existing agents and tools, supported by an SDK, CLI, MCP server, and skills—not a new first-party UI yet.
- Automation and portable tooling are supporting capabilities, not the whole product.

Start with the [product vision](docs/vision.md) and [documentation index](docs/README.md). Public research lives in `docs/research/`; private planning documents are intentionally excluded from the public docs index.
